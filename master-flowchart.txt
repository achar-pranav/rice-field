LINUX INSTALL FEST — MASTER RUNBOOK
=====================================

PRE-FEST PREP (you do this at home)
-------------------------------------
1. Download Ubuntu Server LTS ISO (24.04)
2. Verify checksum: sha256sum ubuntu-server-24.04.iso
3. Flash all 20 USBs using: dd if=ubuntu-server-24.04.iso of=/dev/sdX bs=4M status=progress
4. Label each USB 1-20
5. Clone captive-bypass onto a second tiny USB (fat32, just the script)
6. Test one USB on a spare machine end to end before the fest

PRE-FEST STUDENT INSTRUCTIONS (send this out before the day)
--------------------------------------------------------------
1. Back up all personal data — no exceptions
2. Note down BitLocker recovery key from: Settings > Privacy & Security > Device Encryption > Recovery Key
   OR: aka.ms/myrecoverykey (Microsoft account)
3. Disable BitLocker if possible: Control Panel > BitLocker Drive Encryption > Turn Off
4. Take a photo of your current BIOS boot order screen (just in case)
5. Know your Windows partition sizes so you can shrink the right one

ON THE DAY — PER MACHINE FLOW
-------------------------------

PHASE 1: WINDOWS SIDE (do this before touching BIOS)
------------------------------------------------------
1. Boot into Windows normally
2. Open Disk Management (Win+X > Disk Management)
3. Right click C: drive > Shrink Volume
4. Shrink by at least 50000 MB (50GB) for Linux
5. Leave the shrunk space as "Unallocated" — do not format it
6. If BitLocker is still on: disable it now, wait for decryption to finish (can take 10-30 mins on slow machines)
7. Disable Fast Startup: Control Panel > Power Options > Choose what power buttons do > Turn off fast startup
8. Disable Secure Boot:
   - Restart > hold F2/F10/DEL (varies by brand) during POST to enter BIOS
   - Navigate to Security or Boot tab
   - Set Secure Boot = Disabled
   - Save and exit
9. Set USB as first boot device in BIOS boot order
10. Save and exit BIOS

COMMON BIOS KEYS BY BRAND:
- Lenovo: F2 or Fn+F2 (ThinkPads: F1)
- Dell: F2 for BIOS, F12 for one-time boot menu
- HP: F10 for BIOS, F9 for boot menu
- Asus: F2 for BIOS, F8 for boot menu
- Acer: F2 for BIOS, F12 for boot menu

PHASE 2: BOOTING THE USB
--------------------------
1. Insert USB into machine
2. Power on, hit boot menu key immediately (spamming works)
3. Select USB from boot menu
4. GRUB screen appears — select "Ubuntu Server" (first option is fine)
5. Wait for boot — you will see a lot of text scrolling
6. System is fully in RAM when you see the login prompt
7. LOGIN PROMPT = SAFE TO YANK USB
8. Yank USB, hand it to next person in queue
9. Log in: username "ubuntu", no password (or whatever the live session default is)

PHASE 3: CAPTIVE PORTAL BYPASS
--------------------------------
1. Check network interface name: ip link show
   (usually eth0 or wlan0 or enp2s0 — note it down)
2. Check wifi status: nmcli dev status
3. Connect to PESU wifi: nmcli dev wifi connect "NETWORK_NAME" password "PASSWORD"
   (if open network just: nmcli dev wifi connect "NETWORK_NAME")
4. Copy captive-bypass script from second USB:
   - Insert second USB (the fat32 one with the script)
   - mount /dev/sdb1 /mnt (adjust sdb1 to actual device, check with lsblk)
   - cp /mnt/captive-bypass.sh ~/
   - umount /mnt
   - Remove second USB
5. Make script executable: chmod +x ~/captive-bypass.sh
6. Run script: ./captive-bypass.sh
7. Enter SRN when prompted
8. Enter password when prompted
9. Confirm SSID when prompted
10. Wait for "Captive portal login successful"
11. Verify internet: ping -c 3 google.com

PHASE 4: UBUNTU SERVER LIVE INSTALL
-------------------------------------
NOTE: At this point you are running live from RAM with internet access.
The next steps install Ubuntu to the actual disk.

1. Run the installer: sudo ubuntu-server-install
   OR if that doesn't work: sudo subiquity-installer
   OR fallback: just run the curses installer that may have auto-launched

   Actually on Ubuntu Server live the installer launches automatically.
   If it didn't: sudo systemctl start snap.subiquity.subiquity.service

2. Language: English
3. Keyboard: detect or select manually
4. Network: should already be connected via captive-bypass — confirm it shows connected
5. Storage:
   !! WARNING SCREEN — READ CAREFULLY !!
   - Select "Custom storage layout" — NOT the automatic option
   - You will see your disks listed
   - Find the "Unallocated" space you created in Windows (should be ~50GB)
   - Create partitions manually:
     a. EFI partition: IF there is already an EFI partition (look for "fat32" ~512MB) DO NOT CREATE ANOTHER ONE. Just mark it as /boot/efi with "use" not "format"
     b. Root partition: use the unallocated space, format as ext4, mount as /
   - DO NOT touch the Windows NTFS partition
   - DO NOT delete or reformat the existing EFI partition
   - Confirm and proceed

6. Profile setup:
   - Your name, server name, username, password
   - Write this down somewhere

7. SSH: skip for now
8. Snaps: skip everything, no extras
9. Confirm and let installer run (10-20 mins depending on machine)
10. When done: "Reboot Now"
11. Remove any USB if prompted

PHASE 5: FIRST BOOT INTO UBUNTU SERVER (HEADLESS)
---------------------------------------------------
1. Machine boots into TTY — black screen with login prompt, no GUI
2. Log in with the credentials you set during install
3. Verify internet (captive-bypass needs to run again since this is a fresh boot):
   nmcli dev status
4. Connect to wifi again: nmcli dev wifi connect "NETWORK_NAME"
5. Run captive-bypass again (it's not installed yet so you need to set it up):
   git clone https://github.com/achar-pranav/captive-bypass.git
   cd captive-bypass
   chmod +x captive-bypass.sh
   ./captive-bypass.sh
6. Enter credentials again
7. Confirm internet: ping -c 3 google.com

PHASE 6: POST-INSTALL — PULL KDE AND EVERYTHING ELSE
------------------------------------------------------
1. Update package lists:
   sudo apt update

2. Install KDE Plasma (full Kubuntu-style desktop):
   sudo apt install -y kubuntu-desktop

   OR for minimal KDE:
   sudo apt install -y kde-plasma-desktop

   OR for GNOME if someone prefers:
   sudo apt install -y ubuntu-desktop

   This will take 10-30 mins depending on wifi speed. Go get chai.

3. Install browser (if not pulled in by desktop meta-package):
   sudo apt install -y firefox

4. Install common dev tools:
   sudo apt install -y git curl wget vim htop build-essential

5. Set display manager to SDDM (for KDE):
   sudo systemctl enable sddm
   sudo systemctl set-default graphical.target

6. Reboot:
   sudo reboot

PHASE 7: FIRST BOOT INTO KDE
------------------------------
1. Machine boots into SDDM login screen (graphical)
2. Log in with your credentials
3. KDE Plasma desktop loads
4. You are on Wayland by default on modern KDE — confirm by:
   echo $XDG_SESSION_TYPE (should say "wayland")
5. Connect to wifi via the GUI network manager in the system tray
6. Run captive-bypass one final time:
   Open terminal (Konsole)
   cd captive-bypass
   ./captive-bypass.sh --install
   (this installs the NetworkManager dispatcher so it runs automatically on every wifi connect)

7. Done. System is fully operational.

GRUB NOTES (important)
------------------------
- Ubuntu installer handles GRUB automatically
- It detects Windows and adds it to the GRUB menu
- On reboot you will see GRUB with two options: Ubuntu and Windows Boot Manager
- If Windows does not appear: sudo os-prober && sudo update-grub
- If GRUB does not appear at all and boots straight to Windows:
  Boot into BIOS > change boot order > put "ubuntu" or "grub" above Windows Boot Manager
- If machine boots to a black screen after installer: likely Secure Boot is still on — go back to BIOS and disable it

EFI WARNINGS (read before touching storage)
--------------------------------------------
- Every modern dual boot machine has ONE EFI partition (fat32, ~100-512MB, on the same disk as Windows)
- Never delete it. Never format it. Never create a second one.
- Just mount it as /boot/efi during the custom storage step
- If you accidentally delete it: Windows will not boot. Recovery is painful.
- The Ubuntu installer will warn you if you're about to do something destructive — READ the warnings

COMMON PROBLEMS AND FIXES
---------------------------
Problem: GRUB not showing, boots straight to Windows
Fix: BIOS > Boot Order > move grub/ubuntu above Windows

Problem: "No internet" after captive-bypass says success
Fix: ping 8.8.8.8 first. If that works but domains don't, DNS issue:
     echo "nameserver 8.8.8.8" | sudo tee /etc/resolv.conf

Problem: apt install hangs or is very slow
Fix: Change mirror — sudo nano /etc/apt/sources.list
    Replace "archive.ubuntu.com" with "in.archive.ubuntu.com" (India mirror, faster from PESU)

Problem: KDE login loop (logs in then drops back to SDDM)
Fix: Check disk space — df -h / — if root partition is full, apt ran out of space mid-install
    Free space or re-run apt install kubuntu-desktop

Problem: No wifi adapter showing in nmcli
Fix: sudo apt install linux-firmware && sudo reboot
    (some wifi cards need firmware blobs)

Problem: Screen is black after reboot but before login
Fix: It's probably just Plymouth (boot splash). Wait 30 seconds.
    If persists: at GRUB, press E, add "nomodeset" to linux line, boot

Problem: Secure Boot error on first boot
Fix: BIOS > Security > Secure Boot > Disabled

USB HANDOFF LOGISTICS FOR 200 PEOPLE
--------------------------------------
- 20 USBs running in parallel
- Each USB serves ~10 people sequentially
- Average time per machine (Phase 2 boot to yank): 4-7 mins on USB 3.0
- Phases 3-6 are done WITHOUT the USB (it's already been yanked and passed on)
- Have 2-3 people per USB station to help with BIOS and partitioning
- The dangerous steps (BIOS + partitioning) need a volunteer to supervise every machine
- Don't let students touch partitioning alone — too much risk
